# Slow Glow · переезд на российский хостинг (чтобы работало без VPN)

Зачем: адреса `*.vercel.app` в России периодически замедляют/блокируют — часть твоих
пользователей просто не может открыть приложение. Переезд на российский VPS убирает
эту проблему полностью: и сайт, и ИИ (GigaChat), и аналитика (Метрика) — всё внутри РФ.
Бонус: на своём сервере работают **пуши «Тебе письмо ✦»** и **синхронизация по коду** —
на Vercel они не работают.

Займёт ~40–60 минут один раз. Ничего страшного в шагах нет — просто иди по порядку.

---

## Шаг 1. Купи VPS (виртуальный сервер)

Подойдёт любой российский: **Timeweb Cloud**, **reg.ru**, **Selectel**, **Beget VPS**.
Минимальный тариф достаточно: 1 CPU, 1–2 ГБ RAM, Ubuntu 22.04+ (~300–500 ₽/мес).

При создании выбери образ **Ubuntu 22.04** и запиши IP-адрес и root-пароль.

## Шаг 2. Подключись к серверу

На Windows — программа PuTTY, на Mac — Терминал:

```
ssh root@ТВОЙ_IP
```

## Шаг 3. Установи Node.js и загрузи проект

```bash
# Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs git

# папка проекта
mkdir -p /opt/slowglow && cd /opt/slowglow
```

Загрузи файлы проекта на сервер. Проще всего — архивом:
запакуй локально папку проекта (без node_modules) в slowglow.zip, затем с компьютера:

```
scp slowglow.zip root@ТВОЙ_IP:/opt/slowglow/
```

и на сервере:

```bash
cd /opt/slowglow && apt-get install -y unzip && unzip slowglow.zip
```

## Шаг 4. Собери и запусти

```bash
cd /opt/slowglow
npm install
npm run build        # соберёт папку dist

# ключ GigaChat — ОБЯЗАТЕЛЬНО (без него ИИ отвечает заглушками)
export GIGACHAT_AUTH_KEY="твой_ключ_из_личного_кабинета_Сбера"

# пробный запуск
node server.js
# увидишь: «Slow Glow слушает порт 8080», «Пуши готовы»
# проверь в браузере: http://ТВОЙ_IP:8080 — приложение должно открыться
# останови: Ctrl+C
```

## Шаг 5. Автозапуск (чтобы жило само, переживало перезагрузки)

```bash
npm install -g pm2
GIGACHAT_AUTH_KEY="твой_ключ" SG_PUSH_HOUR=9 pm2 start server.js --name slowglow
pm2 save && pm2 startup   # выполни команду, которую pm2 напечатает
```

Полезные команды: `pm2 logs slowglow` (логи), `pm2 restart slowglow` (перезапуск после обновления).

## Шаг 6. Домен и HTTPS

1. Купи домен (например slow-glow.ru) у reg.ru / Timeweb (~200–400 ₽/год).
2. В панели домена создай **A-запись**: `@ → ТВОЙ_IP` (и `www → ТВОЙ_IP`).
3. HTTPS проще всего через **Caddy** (сам получает сертификат):

```bash
apt-get install -y caddy
printf 'slow-glow.ru {\n  reverse_proxy 127.0.0.1:8080\n}\n' > /etc/caddy/Caddyfile
systemctl restart caddy
```

Через 5–10 минут https://slow-glow.ru откроет приложение с замочком.

## Шаг 7. Проверь всё

- Приложение открывается с телефона **без VPN** ✓
- Анализатор пинов отвечает (значит GIGACHAT_AUTH_KEY подхвачен) ✓
- В «Конверте дня» появилась кнопка «Напоминать о письме по утрам» (пуши живы) ✓
- В профиле появилась карточка «Синхронизация между устройствами» ✓
- Метрика: раздел «В реальном времени» показывает твой визит ✓

## Как обновлять приложение потом

```bash
cd /opt/slowglow
# заменяешь изменённые файлы (scp/загрузка), затем:
npm run build && pm2 restart slowglow
```

Правило: обновляй все изменённые файлы за один раз (App.jsx / appdata.js /
service-worker.js / картинки), чтобы не ловить «что-то сбилось».

## Переменные окружения (справочно)

| Переменная            | Зачем                                        | По умолчанию |
|-----------------------|----------------------------------------------|--------------|
| GIGACHAT_AUTH_KEY     | ключ GigaChat — без него ИИ на заглушках     | (пусто)      |
| GIGACHAT_MODEL        | текстовая модель                              | GigaChat-Pro |
| SG_PUSH_HOUR          | час утренней пуш-рассылки (по времени сервера)| 9            |
| SG_ALLOWED_ORIGIN     | доп. разрешённый домен для ИИ-запросов        | (пусто)      |
| PORT                  | порт сервера                                  | 8080         |

Данные сервера (пуш-подписки, VAPID-ключи, облачные копии синхронизации)
хранятся в папке `data/` рядом с server.js — не удаляй её при обновлениях.
